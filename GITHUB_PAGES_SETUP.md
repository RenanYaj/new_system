# GitHub Pages Setup Instructions

## How to Enable Your Monthsary Website on GitHub Pages

Follow these steps to make your website accessible at: `https://renanyaj.github.io/new_system/`

### Step 1: Go to Your Repository Settings
1. Open your browser and go to: https://github.com/RenanYaj/new_system
2. Click on **Settings** (top right, near the tabs)

### Step 2: Enable GitHub Pages
1. In the left sidebar, scroll down and click **Pages**
2. Under **Source**, select:
   - Branch: **main**
   - Folder: **/ (root)**
3. Click **Save**

### Step 3: Wait for Deployment
- GitHub will start building your site (takes 1-2 minutes)
- You'll see a message: "Your site is ready to be published at..."
- Refresh the page after a minute

### Step 4: Get Your Link
Once deployed, your website will be live at:
```
https://renanyaj.github.io/new_system/
```

**That's the link you share with your girlfriend!** 🎉

## Notes:
- The website works completely offline on GitHub Pages (no PHP needed)
- Photos are in the `public/` folder
- Video is hosted on Google Drive (opens in new tab)
- Updates to your code will automatically update the website within 1-2 minutes

## Troubleshooting:
If images don't show:
- Make sure all images are in the `public/` folder
- Check that image filenames match exactly (case-sensitive)

If the site doesn't load:
- Wait 2-3 minutes after enabling GitHub Pages
- Clear your browser cache (Ctrl+Shift+Delete)
- Try opening in incognito/private mode
